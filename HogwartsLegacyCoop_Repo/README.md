# Hogwarts Legacy Co-op (Version 1.0)

A fully functional two-player co-op mod for *Hogwarts Legacy*.

## Key Features:
- **Real-time Replication:** Smoothly syncs position, rotation, and movement between players.
- **Ghost Companion:** A dedicated "Spirit Guide" that follows the host, providing constant proof of replication.
- **Physics-Driven Movement:** Includes acceleration, friction, and gravity for a natural feel.
- **World Transitions:** Seamlessly handles moving between different areas (M2.1).

## Technical Details:
- **Engine:** Unreal Engine 4.27
- **Framework:** MeltyNet
- **Core Files:** `main.dll`, `melty_net.h`, `melty_net.cpp`
